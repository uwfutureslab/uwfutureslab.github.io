The character, described

Concept

A single command line stands in for the old world of building software: a > prompt and a blinking cursor. A student types an ordinary request in plain language — build my app, teach me chemistry, analyze this data — and at the end of the sentence the cursor blooms into a four-color spark: the thing they asked for, now real. That's the whole thesis of Futures Lab in one gesture — you describe it, it exists — and the spark carries Google's four colors, so the brand partnership lives inside the payoff rather than being bolted on.

Anatomy

>  the prompt — Google Blue, weight 700
_  the cursor — a blue underscore that blinks
✦  the spark — a 4-point sparkle, one
    Google color per quadrant (the payoff)

The spark is a four-pointed star with concave sides — a "sparkle," not a compass star — sized ~1.5× the cap height so it reads as the hero of the line. It sits exactly where the cursor was, so the eye reads transformation, not replacement.

Motion (the "type, then bloom" loop)

0.0s  >_ — the underscore cursor blinks
      4 times (~0.5s per tick)
2.1s  bloom — cursor fades as the spark
      scales up (ease-out, slight rotate)
2.6s  spark holds & gently twinkles
4.0s  mark fades, resets, loops

Total loop ≈ 4.2s. Respects prefers-reduced-motion: motion-sensitive visitors see the finished state (> ✦) with no animation.

✓ Do
  • Let the spark be the only place all four colors meet.
  • Keep the prompt monospace — it signals "command line / build."
  • Swap the typed request freely; keep it lowercase & plain-language.
  • Give it room; the spark needs air to bloom.
✕ Don't
  • Don't recolor the chevron or cursor rainbow — restraint sells the bloom.
  • Don't set the request in a rounded/handwritten font.
  • Don't stretch the spark; scale it uniformly.
  • Don't add a second spark near the mark — one payoff.

Drop it into your site

Self-contained — no libraries, no fonts to load. Paste this where you want the animated mark (a hero header, a nav bar). Change BLINKS for more or fewer ticks before the bloom.

<!-- Futures Lab animated mark -->
<span class="fl-term" role="img" aria-label="Futures Lab">
  <span class="fl-chev">></span><span class="fl-slot">
    <span class="fl-cursor"></span>
    <svg class="fl-spark" viewBox="-50 -50 100 100" aria-hidden="true">
      <path d="M0 0 L0 -46 Q0 0 46 0 Z" fill="#4285F4"/>
      <path d="M0 0 L46 0 Q0 0 0 46 Z" fill="#EA4335"/>
      <path d="M0 0 L0 46 Q0 0 -46 0 Z" fill="#FBBC05"/>
      <path d="M0 0 L-46 0 Q0 0 0 -46 Z" fill="#34A853"/>
    </svg>
  </span>
</span>

<style>
.fl-term{font-family:ui-monospace,"SF Mono","Roboto Mono",Menlo,monospace;font-weight:700;
  font-size:40px;display:inline-flex;align-items:center;gap:.09em;color:#E7ECF3;transition:opacity .42s}
.fl-chev{color:#4285F4}
.fl-slot{position:relative;display:inline-block;width:1.15em;height:1.15em}
.fl-cursor{position:absolute;left:.03em;bottom:.26em;width:.52em;height:.14em;background:#4285F4;
  border-radius:3px;box-shadow:0 0 10px rgba(66,133,244,.5);transition:opacity .12s}
.fl-spark{position:absolute;left:50%;top:50%;width:100%;height:100%;
  transform:translate(-50%,-50%) scale(.1) rotate(-40deg);opacity:0;
  transition:transform .5s cubic-bezier(.18,.85,.25,1),opacity .34s}
.fl-term.bloom .fl-spark{transform:translate(-50%,-50%) scale(1) rotate(0);opacity:1}
</style>

<script>
(function(){
  var BLINKS=4;                            // ← ticks before the bloom
  var t=document.querySelector(".fl-term"), cur=t.querySelector(".fl-cursor");
  var wait=function(ms){return new Promise(function(r){setTimeout(r,ms)})};
  if(matchMedia("(prefers-reduced-motion: reduce)").matches){ cur.style.opacity=0; t.classList.add("bloom"); return; }
  (async function loop(){while(true){
    t.classList.remove("bloom"); t.style.opacity=1; cur.style.opacity=1; await wait(520);
    for(var i=0;i<BLINKS;i++){ cur.style.opacity=0; await wait(250); cur.style.opacity=1; await wait(300); }
    cur.style.opacity=0; t.classList.add("bloom"); await wait(1750);
    t.style.opacity=0; await wait(440);
  }})();
})();
</script>
